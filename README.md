# 截图更新助手

本目录是“截图更新助手”项目的唯一工作目录。后续项目代码、配置、文档和资源均存储在这里。

## 版本管理约定

- 使用 Git 进行本地版本管理，使用 GitHub 私有仓库保存远程版本。
- 每完成一个独立功能、修复或阶段性任务，都要先检查修改内容并确认项目可以正常运行，再创建清晰的 commit 并 push。
- 进行可能影响现有功能的大规模修改前，先创建安全 commit。
- 出现问题时，优先通过 `git diff` 和 `git log` 定位，并从稳定版本恢复。
- 未经确认，不删除 Git 历史，也不强制覆盖远程仓库。
